&#x20;电商零售数据分析 (Online Retail II)



项目概述

基于 UCI 提供的英国在线零售商 2009-2011 年交易数据集（约 106 万条记录），使用 Python 进行数据清洗与探索性分析，从销售趋势、商品集中度、地域分布、用户价值（RFM）四个维度挖掘业务洞察。



技术栈

\- Python 3

\- Pandas, Numpy (数据清洗与处理)

\- Matplotlib (数据可视化)

\- Jupyter Notebook



核心发现

1\. \*\*季节性趋势\*\*：销售旺季集中在 Q4（11 月达峰值），1-2 月为淡季。

2\. \*\*商品帕累托\*\*：21.4% 的核心商品（1131种）贡献了 80% 的销售额。

3\. \*\*地域集中度\*\*：高度依赖英国本土市场，贡献占比达 82.98%。

4\. \*\*RFM 用户分层\*\*：22.1% 的“重要价值客户”贡献了 68.35% 的收入。
